# Windows Dynamic Installer!
Thanks for testing! You will need a windows ISO (can be from Windows XP to 11)

## DISCLAIMER 
This is not an official Microsoft Installer! made in Visual Studio 2012!

## REQUIREMENTS!!!
* 7-zip
* An .ISO with Windows XP setup files or later
* A Windows Operating System or Wine
* A USB Drive (formatted to ntfs)
